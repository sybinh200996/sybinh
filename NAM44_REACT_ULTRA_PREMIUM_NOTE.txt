SyNam NAM44 React Ultra Premium
================================

Bản nâng cấp từ NAM42 theo yêu cầu:

1) Giao diện React artifact
- public/index.html dùng React 18 + Babel CDN để chạy trực tiếp như một React artifact không cần build.
- public/app.js viết lại giao diện bằng React component.
- public/style.css viết lại giao diện desktop + mobile ultra premium.

2) Mobile-first
- Màn hình chính mobile ưu tiên hiển thị banner + tab chức năng.
- Bottom navigation cố định cho điện thoại.
- Tab chức năng dạng grid gọn, không xổ lệch nhiều dòng khó nhìn.
- Chat box cao linh hoạt theo màn hình, nhập/gửi giống app AI hiện đại.

3) Banner
- Giữ ảnh trái/phải trong public/assets.
- Ảnh rõ, cover full chiều cao banner.
- Có lớp gradient mờ viền để ảnh hòa vào nền banner.
- Desktop: banner 3 cột cân đối.
- Mobile: ảnh hai bên nhỏ lại, nội dung giữa rõ ràng.

4) Chat AI chuyên nghiệp
- Chat layout desktop có sidebar provider.
- Mobile ẩn sidebar để tập trung chat.
- Bubble user/AI hiện đại.
- Có Copy, Đọc, Thử lại.
- Lưu lịch sử chat trong localStorage.
- Gửi Enter, Shift+Enter xuống dòng.

5) AI thật qua backend
- /api/multi-ai/chat dùng AI Router sẵn có: Gemini, Groq, OpenRouter, OpenAI, Claude, DeepSeek, Grok, Qwen, Mistral.
- Claude hỗ trợ cả CLAUDE_API_KEY và ANTHROPIC_API_KEY trong .env.
- Prompt server đã có quy tắc trả lời chính xác, không bịa, không lộ model/provider.
- Weather/date core của NAM42 được giữ lại.

6) Các tab chức năng
- Trang chủ
- AI Chat
- Xem chỉ tay
- Xem tướng
- Tình duyên
- Tử vi / Luận giải
- AI Keys

Cách chạy:
1. Giải nén zip.
2. npm install
3. Tạo file .env, thêm key ví dụ:
   ANTHROPIC_API_KEY=sk-ant-...
   hoặc CLAUDE_API_KEY=sk-ant-...
   GEMINI_API_KEY=...
   GROQ_API_KEY=...
   OPENROUTER_API_KEY=...
4. npm start
5. Mở http://localhost:3000

Lưu ý:
- React CDN cần internet để tải React/Babel ở lần chạy đầu. Nếu muốn bản offline/bundle Vite, cần build thêm package React riêng.
- Xem ảnh AI vẫn cần GEMINI_API_KEY vì endpoint vision hiện dùng Gemini Vision.
