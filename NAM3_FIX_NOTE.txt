Cách chạy:
1. Giải nén zip.
2. Mở CMD trong thư mục app.
3. Chạy: npm install
4. Tạo file .env từ .env.example và thêm GEMINI_API_KEY.
5. Chạy: npm start
6. Mở: http://localhost:3000
7. Bấm "🧪 Test kết nối Gemini" để kiểm tra API.

Nếu vẫn báo server Gemini:
- Kiểm tra GEMINI_API_KEY trong .env không có dấu ngoặc kép thừa.
- Thử đổi mạng/VPN/proxy.
- Kiểm tra quota tài khoản Google AI Studio.
- Có thể thêm GEMINI_MODEL=gemini-2.5-flash vào .env.

NAM3 MODEL SWITCH FIX:

- Có chế độ Auto: tự thử lần lượt nhiều model nếu model đầu bị lỗi/quota/không hỗ trợ.
