NAM43 - Claude-style Mobile Premium Upgrade

Đã nâng cấp:
1. Giao diện AI Chat mobile-first gọn hơn, giống ChatGPT/Gemini hơn.
2. Ẩn tab Chỉnh sửa ảnh AI trên mobile để tránh rối banner/chat; desktop vẫn giữ đầy đủ.
3. Thêm nút Copy và Thử lại ngay dưới câu trả lời AI.
4. Lưu payload câu hỏi gần nhất để regenerate không gửi lặp lung tung.
5. Hỗ trợ Claude bằng cả CLAUDE_API_KEY và ANTHROPIC_API_KEY trong .env.
6. /api/chat-ai không còn chết cứng khi thiếu GEMINI_API_KEY: nếu có provider khác như Claude/Groq/OpenRouter thì fallback text chat vẫn chạy.
7. Tối ưu bong bóng chat, markdown, code block, ô nhập sticky cho điện thoại.

Gợi ý .env:
GEMINI_API_KEY=...
CLAUDE_API_KEY=...
# hoặc
ANTHROPIC_API_KEY=...
GROQ_API_KEY=...
OPENROUTER_API_KEY=...

Chạy thử:
npm install
npm start
Mở: http://localhost:3000
