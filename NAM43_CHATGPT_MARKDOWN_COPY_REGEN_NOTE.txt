NAM43 - ChatGPT Style Chat Upgrade

Đã nâng cấp trực tiếp từ NAM42:
1. Sửa markdownish:
   - Hỗ trợ # heading, ##, ###...
   - Hỗ trợ **bold**, _italic_, `inline code`.
   - Hỗ trợ danh sách gạch đầu dòng và danh sách đánh số 1. 2. 3.
   - Hỗ trợ code block ```...``` có header và nút Copy riêng.
   - Không escape HTML sai thứ tự gây mất markdown.

2. Tin nhắn chat chuyên nghiệp hơn:
   - Avatar người dùng / Sỹ Năm AI.
   - Timestamp rõ ràng.
   - Bubble giống ChatGPT hơn, tối ưu mobile.
   - Nút Copy cho từng tin nhắn AI và tin nhắn người dùng.
   - Nút Thử lại / Regenerate cho câu trả lời AI gần nhất.

3. Mobile chat:
   - Giữ input sticky, gọn hơn.
   - Bubble co giãn tốt hơn, không tràn ngang.
   - Code block cuộn ngang/hiển thị đẹp hơn trên điện thoại.

File đã sửa:
- public/app.js
- public/style.css

Ghi chú: Bản này ưu tiên vá UI/UX chat, không đổi server.js để tránh ảnh hưởng API đang chạy.
