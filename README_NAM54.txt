SyNam Mystic NAM54 GEMINI STYLE

Đã chỉnh theo yêu cầu:
- Thay ảnh banner bên phải bằng ảnh bạn vừa tải lên.
- Banner thiết kế lại theo hướng Gemini/ChatGPT: gọn hơn, tập trung vào SyNam Mystic và ô hỏi AI.
- Hai ảnh banner dùng hiệu ứng mờ viền để hòa vào nền.
- Desktop có nền động aurora/star nhẹ.
- Đổi wording giao diện từ “Đặng Năm AI” sang “SyNam AI / SyNam Mystic” để bớt cảm giác diễn giải tào lao.
- Giữ nguyên các module: Chat AI, tử vi, tình duyên, thần số học, chiêm tinh, xem tay, xem tướng, phong thủy, bói bài, cài đặt API.

Cách chạy:
1. npm install
2. tạo .env theo .env.example
3. npm start
4. mở http://localhost:3000
