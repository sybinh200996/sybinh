NAM29 VOICE UX PRO - Sỹ Năm

Nâng cấp chính:
1. Chatbox đổi từ input 1 dòng sang textarea nhiều dòng.
2. Ô chat tự mở rộng khi gõ hoặc khi micro đang nhận giọng nói.
3. Nhấn Enter để gửi nhanh, Shift + Enter để xuống dòng.
4. Khi đọc/nhập bằng giọng nói, nội dung đang nhận sẽ hiện rõ trong ô chat.
5. Sau khi ngừng nói/đọc 3 giây, app tự gửi câu hỏi cho AI trả lời.
6. Sau khi gửi xong, ô chat tự thu lại gọn.
7. Giữ nguyên lõi NAM28: vá AI loạn, ngày giờ, thời tiết local-live-weather.

File chỉnh chính:
- public/index.html
- public/app.js
- public/style.css

Cách chạy:
1. npm install
2. npm start
3. Mở http://localhost:3000

Ghi chú:
- Tính năng nhận giọng nói phụ thuộc trình duyệt. Chrome/Edge Android hỗ trợ tốt nhất.
- Nếu trình duyệt chặn micro, cần cấp quyền Microphone cho trang web.
