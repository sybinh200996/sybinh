NAM33 - REAL DASHBOARD + BANNER BLEND FIX

Đã chỉnh sửa app thật, không tạo ảnh:
1. Ba bảng cuối trang chủ hoạt động thật:
   - Lịch sử phân tích: mở lịch sử, xem chi tiết, xóa lịch sử, xuất TXT.
   - Giọng nói AI: chọn giọng, chỉnh tốc độ, test giọng, đọc kết quả mới nhất, dừng đọc.
   - Thống kê của bạn: đếm phân tích, câu hỏi AI, ảnh/file, ngày sử dụng.

2. Banner phải:
   - Ảnh bên phải hiển thị vừa khớp banner.
   - Làm mờ viền bằng CSS mask/radial-gradient.
   - Hòa ảnh vào nền banner, bớt cảm giác ảnh bị dán cứng.

3. Giữ lại các bản vá NAM30/NAM31/NAM32:
   - AI nhớ hội thoại.
   - Ẩn model/provider.
   - Thời tiết Việt Trì/Phú Thọ dùng Open-Meteo.
   - Markdown trong chat hiển thị đẹp hơn.

Cách chạy:
npm install
npm start

Deploy Namecheap/Render: dùng server.js làm startup file.
