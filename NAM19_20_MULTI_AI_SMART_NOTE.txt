SyNam Mystic Ultimate Pro - NAM19+20 MULTI-AI SMART

Đã gộp ý tưởng NAM19 và NAM20:

1. Multi-AI Provider Manager
- Gemini
- ChatGPT/OpenAI
- Claude
- DeepSeek
- Grok/xAI
- Qwen
- Mistral

2. API Key Manager
- Người dùng đăng nhập có thể vào Cài đặt Multi-AI để nhập API key cá nhân.
- Server cũng hỗ trợ key trong .env.
- Có key nào thì AI đó sáng; không có thì tự ẩn.

3. AI Router + Fallback
- Chat có chọn: Auto Router, Gemini, OpenAI, Claude, DeepSeek, Grok, Qwen, Mistral.
- Auto Router tự ưu tiên theo nội dung câu hỏi.
- Nếu AI lỗi, server tự thử provider kế tiếp.

4. Hội Đồng AI
- Bật checkbox Hội Đồng AI trong trang Chat.
- App gọi tối đa 5 AI đã cấu hình và hiển thị từng ý kiến.

5. API mới
- GET  /api/ai/providers
- GET  /api/ai/user-keys
- POST /api/ai/user-keys
- POST /api/multi-ai/chat

Lưu ý bảo mật:
- Bản này lưu API key cá nhân trong data/users.json để test nhanh trên Render/Namecheap.
- Khi thương mại hóa nên mã hóa API key hoặc chuyển sang database/vault an toàn.

Deploy:
- Render: npm install / npm start.
- Namecheap: Node.js 20.x, startup file server.js, npm install, restart app.
